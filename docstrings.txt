 SABOR & CLICK — DOCSTRINGS NO PADRÃO GOOGLE
================================================================================

Este arquivo reúne as docstrings corrigidas/criadas para TODAS as funções do
projeto, organizadas por arquivo. Seguem o padrão Google (Args / Returns /
Raises) e usam a anotação de tipo do Python (-> ) para indicar retornos.

Convenções adotadas:
  - Funções triviais (getters diretos, wrappers de uma linha) receberam uma
    docstring de linha única — a documentação Google completa seria exagero
    nesses casos (conforme autorizado).
  - Onde a assinatura tinha anotação de retorno incompleta/ausente, a docstring
    descreve o tipo retornado real e sugere a anotação `-> Tipo`.
  - Foram documentados também módulos e classes (modelos ORM) quando agregam
    contexto relevante.
  - OBSERVAÇÕES marcam divergências entre a docstring existente e o que a
    função realmente faz, para você revisar.

Legenda: cada bloco mostra a ASSINATURA seguida da docstring sugerida.

MÓDULO triggers.py
    """Criação da trigger de baixa automática de estoque no banco (SQLite)."""

def criar_trigger_baixa_estoque() -> None:
    """Cria a view, a tabela auxiliar e a trigger de baixa de estoque.

    Monta a estrutura necessária para dar baixa no estoque quando um pedido é
    confirmado:
      1. view `consumo_ingrediente_pedido`: consolida o consumo de cada
         ingrediente por pedido (pratos e bebidas somados).
      2. tabela `baixa_lote_pedido`: guarda temporariamente a distribuição da
         baixa entre os lotes.
      3. trigger `baixa_estoque_pedido_confirmado`: ao mudar o status de um
         pedido para 'confirmado', valida o estoque, distribui a baixa entre os
         lotes (priorizando validade mais próxima) e atualiza o estoque geral.

    A operação é idempotente (usa IF NOT EXISTS / DROP IF EXISTS) e executa
    dentro de uma transação com a engine do SQLAlchemy.
    """
